# Back End Development and APIs Certification Projects

This repository contains all the projects I built while working through the Back End Development and APIs certification from freeCodeCamp.

The curriculum focuses on using **Nodejs**, **Express**, **MongoDB**, and **Mongoose** to build back-end applications and RESTful APIs.

## 🧠 What I Learned

- Managing packages with npm
- Creating back-end servers using Node.js and Express
- Routing and middleware in Express
- Working with MongoDB and designing schemas using Mongoose
- Creating, reading, updating, and deleting documents in a NoSQL database
- Building and testing APIs and microservices

## 📦 Courses Breakdown

1. Managing Packages with NPM

- Understanding package.json
- Adding dependencies
- Using scripts


2. Basic Node and Express

- Creating servers
- Handling routes
- Serving static files

3. MongoDB and Mongoose

- Connecting to MongoDB
- Creating Mongoose schemas and models
- CRUD operations
- Query helpers and filters
